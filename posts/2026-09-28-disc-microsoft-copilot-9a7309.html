Microsoft 将从 Teams 聊天列表移除 Copilot 快捷方式

2026-09-28 23:23 EDT　·　AI 整理　·　依据 50 家来源（网络）　·　2635 字

Microsoft 正在对其 Copilot 产品线进行大规模重构。根据多家媒体报道和 Microsoft 官方博客的信息，公司将在下个月从 Microsoft Teams 的聊天列表中移除 Copilot 快捷方式。这一调整是 Microsoft 重新定位 Copilot 战略的一部分，旨在将重点从个人聊天机器人转向面向业务用户的统一 AI 工作空间。

此次变动的核心在于 Microsoft 将 Copilot 重新打造为一个包含 Home、Code 和 Autopilot 三个标签页的统一应用。这一新架构 announced on September 25, 2026, by Jared Spataro, Microsoft’s Chief Marketing Officer for AI at Work. 取代了此前消费者与商业版的分割模式。对于普通用户而言，最直观的变化就是 Teams 聊天列表中的 Copilot 入口将不复存在。多家媒体指出，这标志着 Microsoft 在个人 AI 聊天机器人竞争中的退缩，转而专注于企业级应用。

在功能层面，新的 Copilot 体验不再仅仅是嵌入各个 Office 应用中的助手，而是试图成为 AI 驱动的工作空间中心。Home 标签页将作为文档、聊天、委托任务和 Office 文件的中央枢纽。Code 标签页旨在民主化解决方案构建，使组织内的更多人员能够参与开发工作。Autopilot 标签页则引入了受治理的、持久的代理，能够参与长期的工作流程。Microsoft 表示，未来用户将不再需要手动选择模式，只需描述期望的结果，Copilot 就会自动将其路由到 Chat、Cowork 或 Code。

然而，这种架构变化伴随着计费模式的显著调整。Microsoft 正在将 Copilot 分为两个计费层级。用户订阅许可证涵盖 Copilot 在 Chat、Word、Excel、PowerPoint、Outlook 和 Teams 中的使用。而 Cowork、Code、Autopilot 以及长时间运行的代理式功能则适用基于使用量的计费方式。包括 Astra 和 Fable 在内的高级模型也落入基于使用量计费的范畴。TechTarget 在 2026 年 4 月报道了 Microsoft 365 Copilot 企业版定价为每用户每月 30 美元，按年计费，中小型企业版本的价格范围则在每用户每月 18 至 21 美元之间。对于个人用户，Microsoft 365 Personal 订阅的价格为每月 9.99 美元，这是使用桌面应用中 Copilot 功能的入门门槛。

这一计费结构的变化对企业预算管理提出了新的要求。Microsoft 推出了新的 FinOps for AI 工具来应对这一挑战。管理员可以通过 API 设置支出策略，将用户的信用额度请求纳入现有的审批工作流，并限制每个用户组可以使用哪些模型家族。这些设置也会影响 Auto 路由器可以选择的模型范围。业务领导者和管理员能够了解哪些 Cowork 任务产生了最强的成果，从而决定在哪些地方维持、扩展或优化使用。最终，终端用户可以直接在 Microsoft Copilot 中查看自己的信用额度使用情况、剩余余额和使用历史记录，从而在组织的约束范围内更好地管理自己的 AI 使用。

目前，新 Copilot 的各项功能尚未全面普及。根据官方博客和多家媒体的报道，Home 和 Code 将在未来几周内开始向 Frontier 用户推出。Autopilot 则将在月底扩展到私人预览阶段。这一统一的 Copilot 应用将取代之前的消费者/商业分割版本。Microsoft 表示，其 Copilot 继续利用来自 OpenAI 和 Anthropic 的模型以及 Microsoft 自身的模型。在编码产品中，用户可以从多个模型中选择，包括一个来自 Microsoft 的模型，但在 Home 标签页中，没有 Microsoft 模型出现在选项中。CNBC 报道指出，Microsoft 早在今年初就将 OpenAI 的 GPT-5.6 指定为 powering Microsoft 365 Copilot 的首选模型，即使在继续构建自己的 MAI 模型家族并在某些任务中使用 Anthropic 模型的同时也是如此。

对于具体受影响的群体，这一变化意味着不同的事情。Teams 重度使用者，特别是那些习惯于通过聊天列表快捷方式访问 Copilot 的用户，需要适应新的访问方式。虽然 Copilot 在 Teams 中的功能并未完全消失，但入口发生了变化。企业管理员需要关注新的计费结构，特别是基于使用量的部分，因为这可能导致不可预测的成本。他们需要利用新的 FinOps 工具来设置策略，管理信用额度请求，并控制模型访问权限。对于已经为 Microsoft 365 应用束付费的用户，Copilot 在 Chat、Word、Excel、PowerPoint、Outlook 和 Teams 中的使用仍然由用户订阅许可证覆盖，这部分用户的核心体验变化相对较小。

企业用户，特别是那些大量使用 Copilot 进行代码生成、代理式任务和长时间运行工作流的团队，将面临基于使用量的计费。根据多家媒体的报道，Microsoft 在 2026 年 6 月底时，企业为 Copilot 订阅支付的费用已超过 3000 万个订阅。而 Microsoft 365 应用束的付费用户约为 9000 万。对于这些用户来说，新的计费模式意味着需要更精确地监控 AI 使用成本。加拿大工程和专业服务公司 GHD 的数据和 AI 主管 David McLaren 表示，该公司员工开始使用 Copilot 进行会议电话摘要、邮件管理帮助，以及为客户准备演示文稿和分析。GHD 从 2023 年底开始使用 Copilot，先进行了 300 人的试点，随后将该工具推广到全部 12000 名员工。这类大型企业用户将是新计费模式影响的重点群体。

消费者用户方面，Microsoft Copilot 的免费基础体验仍然可用。用户可以通过 copilot.microsoft.com、Windows 任务栏、Edge 和 Bing 访问。然而，这种免费版本只能搜索网络，无法访问用户的个人文档和邮件。要使用能够访问个人文档和邮件的功能，需要 Microsoft 365 Personal 订阅，价格为每月 9.99 美元。Microsoft 365 Premium 订阅则提供更高的 Copilot 使用限制、独家访问高级 AI 功能，以及 Word、Excel、PowerPoint 和 Outlook 等应用中的 Copilot 集成功能，同时还包括高达 6 TB 的云存储（每用户 1 TB）、Microsoft Defender 以及 Designer 和 Clipchamp 等 AI 驱动工具。

在安全和隐私方面，Microsoft 强调了其在 Copilot 使用中的数据处理方式。当启用"Hey Copilot"功能时，Copilot 使用带有设备上唤醒词检测器的麦克风，该检测器仅检测"Hey Copilot"短语。唤醒词检测器使用设备上的 10 秒音频缓冲区，存储在内存中。这段音频缓冲区永远不会被录制或本地存储。当检测到唤醒词时，Copilot Voice Floating UI 将出现并开始建立 Copilot Voice 对话。与此同时，音频缓冲区会将检测到"Hey Copilot"时的音频发送到云端，以帮助回答用户提出的问题。对于工作许可证用户，Copilot 可以访问组织的邮件、文件、聊天和会议记录，而免费消费者版本只能看到网络内容。

市场反应方面，多家财经媒体报道了投资者对 Microsoft 新 Copilot 战略的反应。Yahoo Finance 报道称，Microsoft 的新 Copilot 推动获得了华尔街 5.5 亿美元的投票支持。Seeking Alpha 发布了关于 Microsoft 的"Muse"时刻到来的评级升级报告。Jefferies 表示，Microsoft 的 Copilot 升级加强了长期信心。然而，Bloomberg 报道指出，Microsoft 通过 Copilot 重新启动实际上放弃了个人 AI 聊天机器人竞争。这一战略转向反映了 Microsoft 对 AI 市场格局的重新评估，即企业级应用和统一工作空间可能比个人聊天机器人更具价值。

对于开发者和技术用户，GitHub Copilot 也在同步更新。The GitHub Blog 报道了 GitHub Copilot for Slack 和 Microsoft Teams 的更新。GitHub Copilot 本身是为代码编辑器设计的，支持 VS Code 和其他代码编辑器，对于经过验证的学生和教师免费，其他用户则需要单独许可证。GitHub Copilot 能够访问用户的代码，这与 Microsoft 365 Copilot 访问组织文档和邮件的能力形成对比。

接下来，用户和企业需要关注几个关键时间点。Home 和 Code 的推出将在未来几周内向 Frontier 用户开始，这意味着早期采用者将率先体验新的界面和功能。Autopilot 的私人预览将在月底扩展，这将为用户提供受治理的持久代理的早期访问机会。Microsoft 表示，Agent 365 中的成本管理将扩展到包括 Code 和 Copilot Managed Runtime，计划于 10 月支持使用 Microsoft Copilot Studio 构建的代理。管理员应在此期间准备好 FinOps for AI 工具，设置支出策略，并规划模型访问控制。

对于普通用户，最需要留意的是 Teams 聊天列表中 Copilot 快捷方式的移除时间。虽然具体的移除日期没有在材料中明确说明，但多家媒体报道称将在下个月进行。这意味着用户需要寻找替代的访问路径，可能是通过直接在应用中使用 Copilot 功能，或者通过新的统一 Copilot 应用界面。对于依赖 Teams 中 Copilot 进行日常工作的用户，建议提前熟悉新的访问方式，避免在快捷方式移除后出现操作中断。

企业决策者需要评估新的计费模式对其预算的影响。基于使用量的计费可能导致成本波动，特别是对于那些频繁使用 Code、Autopilot 和长时间运行代理式功能的团队。管理员应利用新的 API 访问权限，设置适当的支出策略，并将信用额度请求整合到现有的审批流程中。同时，应监控哪些任务产生了最佳成果，以便优化 AI 使用策略。

对于个人用户，选择哪个级别的 Microsoft 365 订阅将直接影响 Copilot 的使用体验。免费版本只能提供网络搜索功能，而付费订阅则能访问个人文档和邮件。Microsoft 365 Personal 的 9.99 美元月费提供了基础的 Copilot 集成，而 Microsoft 365 Premium 则提供更高的使用限制和更多的高级功能。用户应根据自己的需求评估哪个级别最适合自己。

总的来说，Microsoft 的这一系列变化代表了从"AI 嵌入应用"到"AI 作为工作空间"的转变。Copilot 正在从一个分散的助手演变为一个统一的工作中心，涵盖文档管理、代码生成和自主代理功能。虽然这一转变为用户带来了更强大的功能和更灵活的工作方式，但也引入了新的计费复杂性和访问方式的变化。用户和企业需要根据自己的使用场景，评估新的架构和计费模式是否符合他们的需求，并做好相应的准备工作。
