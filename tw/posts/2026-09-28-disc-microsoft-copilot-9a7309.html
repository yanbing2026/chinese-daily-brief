Microsoft 將從 Teams 聊天列表移除 Copilot 快捷方式

2026-09-28 23:23 EDT　·　AI 整理　·　依據 50 家來源（網絡）　·　2635 字

Microsoft 正在對其 Copilot 產品線進行大規模重構。根據多家媒體報道和 Microsoft 官方博客的信息，公司將在下個月從 Microsoft Teams 的聊天列表中移除 Copilot 快捷方式。這一調整是 Microsoft 重新定位 Copilot 戰略的一部分，旨在將重點從個人聊天機器人轉向面向業務用戶的統一 AI 工作空間。

此次變動的核心在於 Microsoft 將 Copilot 重新打造爲一個包含 Home、Code 和 Autopilot 三個標籤頁的統一應用。這一新架構 announced on September 25, 2026, by Jared Spataro, Microsoft’s Chief Marketing Officer for AI at Work. 取代了此前消費者與商業版的分割模式。對於普通用戶而言，最直觀的變化就是 Teams 聊天列表中的 Copilot 入口將不復存在。多家媒體指出，這標誌着 Microsoft 在個人 AI 聊天機器人競爭中的退縮，轉而專注於企業級應用。

在功能層面，新的 Copilot 體驗不再僅僅是嵌入各個 Office 應用中的助手，而是試圖成爲 AI 驅動的工作空間中心。Home 標籤頁將作爲文檔、聊天、委託任務和 Office 文件的中央樞紐。Code 標籤頁旨在民主化解決方案構建，使組織內的更多人員能夠參與開發工作。Autopilot 標籤頁則引入了受治理的、持久的代理，能夠參與長期的工作流程。Microsoft 表示，未來用戶將不再需要手動選擇模式，只需描述期望的結果，Copilot 就會自動將其路由到 Chat、Cowork 或 Code。

然而，這種架構變化伴隨着計費模式的顯著調整。Microsoft 正在將 Copilot 分爲兩個計費層級。用戶訂閱許可證涵蓋 Copilot 在 Chat、Word、Excel、PowerPoint、Outlook 和 Teams 中的使用。而 Cowork、Code、Autopilot 以及長時間運行的代理式功能則適用基於使用量的計費方式。包括 Astra 和 Fable 在內的高級模型也落入基於使用量計費的範疇。TechTarget 在 2026 年 4 月報道了 Microsoft 365 Copilot 企業版定價爲每用戶每月 30 美元，按年計費，中小型企業版本的價格範圍則在每用戶每月 18 至 21 美元之間。對於個人用戶，Microsoft 365 Personal 訂閱的價格爲每月 9.99 美元，這是使用桌面應用中 Copilot 功能的入門門檻。

這一計費結構的變化對企業預算管理提出了新的要求。Microsoft 推出了新的 FinOps for AI 工具來應對這一挑戰。管理員可以通過 API 設置支出策略，將用戶的信用額度請求納入現有的審批工作流，並限制每個用戶組可以使用哪些模型家族。這些設置也會影響 Auto 路由器可以選擇的模型範圍。業務領導者和管理員能夠了解哪些 Cowork 任務產生了最強的成果，從而決定在哪些地方維持、擴展或優化使用。最終，終端用戶可以直接在 Microsoft Copilot 中查看自己的信用額度使用情況、剩餘餘額和使用歷史記錄，從而在組織的約束範圍內更好地管理自己的 AI 使用。

目前，新 Copilot 的各項功能尚未全面普及。根據官方博客和多家媒體的報道，Home 和 Code 將在未來幾周內開始向 Frontier 用戶推出。Autopilot 則將在月底擴展到私人預覽階段。這一統一的 Copilot 應用將取代之前的消費者/商業分割版本。Microsoft 表示，其 Copilot 繼續利用來自 OpenAI 和 Anthropic 的模型以及 Microsoft 自身的模型。在編碼產品中，用戶可以從多個模型中選擇，包括一個來自 Microsoft 的模型，但在 Home 標籤頁中，沒有 Microsoft 模型出現在選項中。CNBC 報道指出，Microsoft 早在今年初就將 OpenAI 的 GPT-5.6 指定爲 powering Microsoft 365 Copilot 的首選模型，即使在繼續構建自己的 MAI 模型家族並在某些任務中使用 Anthropic 模型的同時也是如此。

對於具體受影響的羣體，這一變化意味着不同的事情。Teams 重度使用者，特別是那些習慣於通過聊天列表快捷方式訪問 Copilot 的用戶，需要適應新的訪問方式。雖然 Copilot 在 Teams 中的功能並未完全消失，但入口發生了變化。企業管理員需要關注新的計費結構，特別是基於使用量的部分，因爲這可能導致不可預測的成本。他們需要利用新的 FinOps 工具來設置策略，管理信用額度請求，並控制模型訪問權限。對於已經爲 Microsoft 365 應用束付費的用戶，Copilot 在 Chat、Word、Excel、PowerPoint、Outlook 和 Teams 中的使用仍然由用戶訂閱許可證覆蓋，這部分用戶的核心體驗變化相對較小。

企業用戶，特別是那些大量使用 Copilot 進行代碼生成、代理式任務和長時間運行工作流的團隊，將面臨基於使用量的計費。根據多家媒體的報道，Microsoft 在 2026 年 6 月底時，企業爲 Copilot 訂閱支付的費用已超過 3000 萬個訂閱。而 Microsoft 365 應用束的付費用戶約爲 9000 萬。對於這些用戶來說，新的計費模式意味着需要更精確地監控 AI 使用成本。加拿大工程和專業服務公司 GHD 的數據和 AI 主管 David McLaren 表示，該公司員工開始使用 Copilot 進行會議電話摘要、郵件管理幫助，以及爲客戶準備演示文稿和分析。GHD 從 2023 年底開始使用 Copilot，先進行了 300 人的試點，隨後將該工具推廣到全部 12000 名員工。這類大型企業用戶將是新計費模式影響的重點羣體。

消費者用戶方面，Microsoft Copilot 的免費基礎體驗仍然可用。用戶可以通過 copilot.microsoft.com、Windows 任務欄、Edge 和 Bing 訪問。然而，這種免費版本只能搜索網絡，無法訪問用戶的個人文檔和郵件。要使用能夠訪問個人文檔和郵件的功能，需要 Microsoft 365 Personal 訂閱，價格爲每月 9.99 美元。Microsoft 365 Premium 訂閱則提供更高的 Copilot 使用限制、獨家訪問高級 AI 功能，以及 Word、Excel、PowerPoint 和 Outlook 等應用中的 Copilot 集成功能，同時還包括高達 6 TB 的雲存儲（每用戶 1 TB）、Microsoft Defender 以及 Designer 和 Clipchamp 等 AI 驅動工具。

在安全和隱私方面，Microsoft 強調了其在 Copilot 使用中的數據處理方式。當啓用"Hey Copilot"功能時，Copilot 使用帶有設備上喚醒詞檢測器的麥克風，該檢測器僅檢測"Hey Copilot"短語。喚醒詞檢測器使用設備上的 10 秒音頻緩衝區，存儲在內存中。這段音頻緩衝區永遠不會被錄製或本地存儲。當檢測到喚醒詞時，Copilot Voice Floating UI 將出現並開始建立 Copilot Voice 對話。與此同時，音頻緩衝區會將檢測到"Hey Copilot"時的音頻發送到雲端，以幫助回答用戶提出的問題。對於工作許可證用戶，Copilot 可以訪問組織的郵件、文件、聊天和會議記錄，而免費消費者版本只能看到網絡內容。

市場反應方面，多家財經媒體報道了投資者對 Microsoft 新 Copilot 戰略的反應。Yahoo Finance 報道稱，Microsoft 的新 Copilot 推動獲得了華爾街 5.5 億美元的投票支持。Seeking Alpha 發佈了關於 Microsoft 的"Muse"時刻到來的評級升級報告。Jefferies 表示，Microsoft 的 Copilot 升級加強了長期信心。然而，Bloomberg 報道指出，Microsoft 通過 Copilot 重新啓動實際上放棄了個人 AI 聊天機器人競爭。這一戰略轉向反映了 Microsoft 對 AI 市場格局的重新評估，即企業級應用和統一工作空間可能比個人聊天機器人更具價值。

對於開發者和技術用戶，GitHub Copilot 也在同步更新。The GitHub Blog 報道了 GitHub Copilot for Slack 和 Microsoft Teams 的更新。GitHub Copilot 本身是爲代碼編輯器設計的，支持 VS Code 和其他代碼編輯器，對於經過驗證的學生和教師免費，其他用戶則需要單獨許可證。GitHub Copilot 能夠訪問用戶的代碼，這與 Microsoft 365 Copilot 訪問組織文檔和郵件的能力形成對比。

接下來，用戶和企業需要關注幾個關鍵時間點。Home 和 Code 的推出將在未來幾周內向 Frontier 用戶開始，這意味着早期採用者將率先體驗新的界面和功能。Autopilot 的私人預覽將在月底擴展，這將爲用戶提供受治理的持久代理的早期訪問機會。Microsoft 表示，Agent 365 中的成本管理將擴展到包括 Code 和 Copilot Managed Runtime，計劃於 10 月支持使用 Microsoft Copilot Studio 構建的代理。管理員應在此期間準備好 FinOps for AI 工具，設置支出策略，並規劃模型訪問控制。

對於普通用戶，最需要留意的是 Teams 聊天列表中 Copilot 快捷方式的移除時間。雖然具體的移除日期沒有在材料中明確說明，但多家媒體報道稱將在下個月進行。這意味着用戶需要尋找替代的訪問路徑，可能是通過直接在應用中使用 Copilot 功能，或者通過新的統一 Copilot 應用界面。對於依賴 Teams 中 Copilot 進行日常工作的用戶，建議提前熟悉新的訪問方式，避免在快捷方式移除後出現操作中斷。

企業決策者需要評估新的計費模式對其預算的影響。基於使用量的計費可能導致成本波動，特別是對於那些頻繁使用 Code、Autopilot 和長時間運行代理式功能的團隊。管理員應利用新的 API 訪問權限，設置適當的支出策略，並將信用額度請求整合到現有的審批流程中。同時，應監控哪些任務產生了最佳成果，以便優化 AI 使用策略。

對於個人用戶，選擇哪個級別的 Microsoft 365 訂閱將直接影響 Copilot 的使用體驗。免費版本只能提供網絡搜索功能，而付費訂閱則能訪問個人文檔和郵件。Microsoft 365 Personal 的 9.99 美元月費提供了基礎的 Copilot 集成，而 Microsoft 365 Premium 則提供更高的使用限制和更多的高級功能。用戶應根據自己的需求評估哪個級別最適合自己。

總的來說，Microsoft 的這一系列變化代表了從"AI 嵌入應用"到"AI 作爲工作空間"的轉變。Copilot 正在從一個分散的助手演變爲一個統一的工作中心，涵蓋文檔管理、代碼生成和自主代理功能。雖然這一轉變爲用戶帶來了更強大的功能和更靈活的工作方式，但也引入了新的計費複雜性和訪問方式的變化。用戶和企業需要根據自己的使用場景，評估新的架構和計費模式是否符合他們的需求，並做好相應的準備工作。
