《戰爭機器：E-Day》10月6日全平臺發售 預購及會員權益細則已明確

2026-09-29 01:24 EDT　·　AI 整理　·　依據 42 家來源（網絡）　·　1490 字

《戰爭機器：E-Day》作爲Xbox第一方工作室The Coalition打造的《戰爭機器》系列二十週年紀念作，目前發售安排已全部明確：遊戲將於2026年10月6日正式登陸Xbox Series X/S及PC平臺（支持Steam、Xbox應用），同日加入Xbox Game Pass Ultimate及PC Game Pass會員權益庫。目前遊戲已進廠壓盤，早前開放的測試階段已結束，預購通道持續開放，跨界聯動周邊已部分售罄，核心主創在發售前被裁的事件也引發玩家社區廣泛討論。

發售時間與版本權益

官方公佈的發售流程分爲三個明確階段。第一階段爲2026年8月6日至10日的開放測試，Xbox Game Pass Ultimate及PC Game Pass會員無需預購即可獲得測試資格，預購任意版本遊戲的玩家也可同步參與測試。第二階段爲9月29日太平洋時間上午8點（對應UTC時間15:00）開啓預安裝，玩家可提前在Xbox Series X/S、PC版Xbox應用及Steam平臺下載遊戲資源，遊戲完整安裝包預計大小爲100GB，最終大小以預安裝開啓後的官方數據爲準。第三階段爲分批次正式解鎖：10月1日太平洋時間上午8點，僅高級版（Premium Edition）玩家可提前5天進入遊戲；10月6日太平洋時間上午8點，標準版玩家、典藏版玩家及Xbox Game Pass Ultimate、PC Game Pass會員可正式解鎖遊戲，兩個時間點對應的UTC時間均爲15:00。 遊戲共推出三個版本，所有版本的預購福利均爲Exfil版多姆傳奇角色皮膚與傳奇武器皮膚套裝，福利需通過單次使用兌換碼在對應平臺兌換，具體兌換規則需諮詢預購零售商。標準版售價69.99美元，僅包含基礎遊戲內容與預購福利；高級版售價未公開，除基礎內容與預購福利外，額外包含5天提前遊玩權、Bravo小隊簽名武器包、1000 Iron遊戲貨幣、5個賽季自定義內容包；典藏版售價299.99美元，包含高級版全部內容，額外附贈15英寸遊戲場景雕像、角色卡洛斯·聖地亞哥的COG狗牌複製品、鐵盒包裝及藝術印刷品。預購通道將持續開放至2026年10月6日太平洋時間上午7點59分，過期後將無法獲得預購專屬福利。 Xbox官方明確，僅Game Pass Ultimate及PC Game Pass會員可在10月6日首發日免費遊玩《戰爭機器：E-Day》標準版內容，該權益不包含提前遊玩資格，也不覆蓋遊戲內任何付費內容。Game Pass基礎版、新推出的Starter tier及Premium tier會員無法在首發日獲得遊戲，其中基礎版會員預計要到2027年10月才能解鎖該遊戲。遊戲支持Play Anywhere跨平臺購買權益，玩家在PC或Xbox平臺購買一次即可在兩個平臺共享遊戲進度與內容，目前無PlayStation 5、Nintendo Switch 2版本的發售計劃。

玩法與敘事全面升級

《戰爭機器：E-Day》是系列首款完全基於虛幻引擎5開發的主線作品，未複用任何舊版素材，角色、敵人、武器、音效及場景均從零重建，搭載Epic最新的MegaLights光照系統，整體氛圍更偏暗黑恐怖。遊戲設定在《戰爭機器》初代事件的14年前，即Pendulum Wars（鐘擺戰爭）剛結束的脆弱和平期，地點爲工業城市Kalona，玩家將跟隨年輕的馬庫斯·菲尼克斯與多米尼克·“多姆”·聖地亞哥，以及新角色Bravo小隊成員Mags Carter、Lucas Reyes，親歷Locust族首次湧出地表襲擊Sera星的“湧現日”事件，故事跨度三天，完整呈現Kalona城被摧毀的初期Locust戰爭全貌。 本作是系列歷史上玩法調整幅度最大的作品，首次加入跳躍、滑鏟動作，大幅提升戰鬥的垂直機動性；控制系統全面重做，掩體互動綁定A鍵、衝刺綁定左搖桿按下、翻越與跳躍綁定Y鍵，適配現代玩家的操作習慣。多人模式方面，支持4人在線合作戰役、主機端2人分屏合作，Xbox與PC平臺跨平臺聯機，保留經典4v4對戰模式，新增12人Horde Siege（獸人圍城）模式，三名小隊共同防守Kalona城，玩家可選擇突擊、狙擊、醫療、爆破四個職業。

跨界聯動及周邊情況

爲配合遊戲發售，Xbox聯合餐飲品牌Prince St. Pizza推出定製“湧現派”披薩，玩家購買指定披薩即可獲得遊戲內專屬道具。同時官方推出Lancer槍托造型的披薩切割器，售價60美元，因需求火爆已全部售罄，暫無補貨消息。此外Xbox還與能量飲料品牌Liquid Death聯動，玩家可通過參與活動解鎖傳奇角色姿勢等遊戲內獎勵。

發售前爭議與後續關注節點

有報道稱，遊戲故事總監在遊戲進廠壓盤後僅數天就被裁員，該事件在玩家社區引發廣泛討論，目前The Coalition及Xbox官方未就裁員事件作出公開回應。 對於不同羣體的玩家，後續需關注不同節點：已預購的玩家需注意預購福利兌換碼的有效期，建議在9月29日預安裝開啓後第一時間下載資源，避免正式發售日因服務器擁堵導致下載延遲；Game Pass會員需注意權益檔位的限制，僅Ultimate及PC Game Pass會員可首發日免費遊玩，基礎版會員需等待至2027年10月；計劃購買高級版或典藏版的玩家，可等待10月1日解禁的全球媒體評測參考後再做決定；有意購買聯動周邊的玩家，可關注Xbox官方後續補貨通知，或通過正規二手渠道獲取已售罄的Lancer披薩切割器。目前遊戲已進入發售倒計時階段，所有預購及會員權益規則均已明確，無進一步調整消息。（全文約1980字）
